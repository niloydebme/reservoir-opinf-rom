# Data (excluded from git)

Raw MRST simulation output for the five fixed cases (Ch.4/5/6): snapshot
matrices, well data, rock/grid fields, and parameters — one subfolder per
case under `01_synthetic/`.

**Download:** [10.5281/zenodo.21492749](https://doi.org/10.5281/zenodo.21492749) — `case_studies_data.zip`

Extract into this `data/` folder (e.g. `data/01_synthetic/case1_homogeneous/`)
so the notebooks' relative paths resolve.
