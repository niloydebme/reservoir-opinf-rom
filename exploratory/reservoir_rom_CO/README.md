# reservoir_rom_CO (exploratory, not used in the thesis)

This is a wider parameter sweep (k = 5–500 mD, S = 0–15, 7×7×7 combinations)
that does **not** match the training/validation grids described in the thesis
(Appendix D: 6×6×7 = 252 runs for Ch.7 training, k up to 300 mD).

It's kept here for reference/provenance only — none of its results, figures, or
data feed into the compiled thesis. See the top-level [README](../../README.md)
for the full repo structure.
